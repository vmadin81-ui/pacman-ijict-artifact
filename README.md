# Browser-based application evolution and optimization — research data

Public supplementary data for the IJICT manuscript by Vladimir A. Madin. The manuscript is under preparation; no publication DOI has been assigned.

This repository is a data-only subset. It does not include the historical game implementations, game assets, map geometry, or mixed-source archives. It supports verification of reported numerical results, not full independent execution of the original application experiments. Local measurements and CI measurements are separate.

The initial data deposit is being assembled from the archived research reports. See the file manifest when available.
